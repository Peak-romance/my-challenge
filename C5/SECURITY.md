# Security Policy

## Supported Versions

Only the latest released `0.1.x` line receives security fixes.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1   | :x:                |

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Instead, use one of the following private channels:

- GitHub's private vulnerability reporting (recommended): open
  **Security → Report a vulnerability** on the repository.
- Or email the maintainer via the GitHub handle **@Peak-romance**.

You can expect an acknowledgement within 72 hours. Once triaged, we will keep
you informed of progress and credit you in the advisory unless you prefer to
remain anonymous.
