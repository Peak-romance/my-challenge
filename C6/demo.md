# 演示指引（Demo Walkthrough）

> 在线应用即 demo：**https://idle-asset-platform.app.workbuddy.host/?sharecode=SLUWH4EXLI**
> 演示账号（口令均为 `123456`）：`user1`（部门用户）、`user2`（部门用户）、`admin1`（管理员）

## 一、开场（30 秒）

打开链接 → 登录页 `/index.html` → 点击「测试账号一键填充」或手动输入 `user1 / 123456` → 进入部门用户首页 `/user/home.html`。

首页顶部展示「智能制造学院 / 实训中心」，默认列出全部上架物资（含 `ZC-2026-001` 多抽屉工具柜、`ZC-2026-002` 手动液压堆高车、`ZC-2026-003` 单层钢架床），并有 1 条已领完自动下架的 `ZC-2026-004`。

## 二、部门用户主线（发布 → 认领 → 交接单）

1. **发布物资**：`/user/publish.html` → 学院→部门两级联动 → 填写资产编号/名称/数量/存放地点等 → 多图上传（拍照或相册）→ 提交即上架。
2. **浏览与搜索**：`/user/browse.html` → 按名称/编号/分类/学院/部门/管理部门/存放地点/状态/剩余范围组合筛选与排序。
3. **认领（数量流转）**：进入某物资详情 `/user/asset.html?id=` → 「认领」→ 接收人信息 → 提交后该物资 `remaining_count` 扣减；归零时系统**自动下架**。
4. **交接单**：在认领记录中「生成交接单」→ 服务端**真实导出 Word（.docx）/ PDF** → 可打印或下载归档（含转出/转入部门、接收人、资产信息、签字栏）。
5. **我的记录**：`/user/records.html` → 转出/转入历史、交接单查询、导出 CSV。

## 三、管理员主线（后台）

用 `admin1` 登录，进入 `/admin/`：

1. **组织机构**：学院/部门新增、改名、启用停用、删除；停用部门后其物资自动停止挂牌。
2. **用户与工号**：账号、工号、姓名、学院/部门维护、停用。
3. **物资管理**：全量查看；修正异常物资（逐字段留痕）；强制下架/重新挂牌；**图片真实性核验**（驳回/恢复）；**撤销认领**（数量自动恢复）。
4. **日志中心**：发布/修改/下架/认领/撤销/图片/组织/用户/交接单等日志，**只可查看与导出，不可删除**。
5. **统计报表**：总览、按资产、按部门间调动，导出 CSV。

## 四、可重点验收的“硬核”点

- **图片真实性**：上传同一张图会被内容指纹查重拒绝；上传非图片文件（文件头校验）被拒绝；种子图自动叠加「部门+资产编号+时间」水印。
- **数量闭环**：认领扣减 → 归零下架 → 管理员撤销认领恢复数量，全程一致。
- **权限边界**：管理员不可发布/认领；部门用户不可访问管理员接口；所有导出接口**无 token 必须 401**。
- **不可篡改留痕**：操作日志无删除入口，修正/撤销均写入日志。

## 五、自动化验证（可复现）

仓库内 `tools/smoke_test.py` 覆盖登录→发布（含图片校验）→浏览→搜索→认领扣减→归零下架→流转记录→交接单→我的记录→管理员五模块→统计→权限→导出鉴权→docx/pdf 导出→管理员修正→撤销认领→跨部门发布→部门启用数量规则，**91 项断言全部通过**。

```bash
cd app
python -m venv .venv && .venv/Scripts/python.exe -m pip install -r backend/requirements.txt
.venv/Scripts/python.exe tools/smoke_test.py
```
