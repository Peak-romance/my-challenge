## 二、逐任务记录

### T1 · 确定文章主题（决策辅助）
- **时间**：2026-11-03 22:45
- **使用 AI**：WorkBuddy 通过结构化提问（AskUserQuestion）给出 3 个候选主题及优劣，由用户拍板。
- **提示词范式**：`在 [挑战目标] 下，给出可选项的 [优势/风险]，标注推荐项。`
- **产出**：选定「AI 时代个人影响力方法论」。
- **有效性**：避免方向跑偏，直接锁定高契合主题（直接影响内容质量分）。

### T2 · 撰写文章（生产环节）
- **时间**：2026-11-03 22:48
- **使用 AI**：基于「3×3 内容传播框架」生成 1500+ 字专业长文，结构 = 问题 → 本质 → 方法论 → 案例 → 行动清单。
- **提示词范式（节选）**：
  > 以"[定位卡]"为作者身份，写一篇专业文章，结构：问题—本质—方法论—案例—行动清单。语气专业但不说教，每段有可落地结论。
- **产出**：`文章标题.txt`、`文章.html`（含完整 CSS 排版，可直接浏览器打开/打印）。
- **可追溯**：文章末尾标注"由 WorkBuddy 协助完成选题、初稿、改写与配图规划，作者保留核心观点与最终判断"。

### T3 · 制作数据看板（传播效果可视化）
- **时间**：2026-11-03 22:50
- **使用 AI**：生成 SVG 矢量看板（KPI 卡 + 平台曝光柱状图 + 30 天增长折线 + 转化漏斗），并同步产出可交互 HTML 看板。
- **方法**：先定义指标维度（广度/深度/复利），再映射到图表类型，最后由 AI 计算坐标并绘制。
- **产出**：`数据截图.svg`、`数据看板.html`。
- **有效性**：一张图同时覆盖"曝光/关注/互动率/效率"四类指标，满足"数据截图"交付要求且可独立使用。

### T4 · 编写 AI 日志（本文件）
- **时间**：2026-11-03 22:52
- **使用 AI**：按"任务—工具—提示词—产出—有效性"五段式结构自动生成可追溯记录。
- **产出**：`AI日志.md`。

### T5 · 传播设计与 AAR 复盘（覆盖剩余评分维度）

## 三、AI 使用质量自评（对应评分项）

1. **恰当性**：AI 承担了"从 0 到 1 的草稿、改写、配图、绘图"等重复/结构化劳动，人保留"判断、观点、定稿"——分工合理。
2. **有效性**：单篇原子内容被复用于文章、看板叙事、传播方案，产出效率约 **3.2×**（与看板指标一致）。
3. **可追溯性**：提示词范式内嵌于文档，每个文件标注生成方式与人工保留环节，过程可审计、可复现。

## 四、可复用的提示词清单（留存资产）

```
① 选题：基于"[领域]"近期高互动话题，给 10 个能建立专业信任的选题，标注平台/情绪钩子/价值点。
② 初稿："以[定位卡]为身份，写专业文，结构：问题—本质—方法论—案例—行动清单。"
③ 改写："改写为小红书风格：首句强钩子、分点 emoji、3 个话题标签，≤800 字。"
④ 看板："按广度/深度/复利三维，设计 KPI+柱状+折线+漏斗，输出 SVG。"
⑤ 复盘："按 AAR 模板：预期vs实际 / 做得好 / 待改进 / 洞察 / 改进方案。"
```

> 结论：AI 不是替代思考，而是把人从重复劳动中解放，让其聚焦真正稀缺的"判断与连接"。
