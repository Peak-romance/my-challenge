# capture-note · 想法捕获

## 这个技能解决什么
"顺手记一下"是最高频、也最容易丢的动作。人工记便签的结局通常是：
三处散落、从不回看。本技能把捕获收敛为**双写**：机器可检索的 K 层 + 人类可读的 inbox.md。

## 为什么双写而不是只写文件
只写文件 → 检索不到，等于没记（下次对话用不上）。
只写 K 层 → 人无法用编辑器查看，缺乏"翻本子"的安全感。
两者同时存在，才既有召回又有可读性。

## 契约
| 输入 | 必填 | 说明 |
| --- | --- | --- |
| text | 是 | 原始内容，会触发 K 层去重（同文只增强权重，不重复膨胀） |
| tags | 否 | 默认 `inbox`，建议用领域标签便于日后检索 |

## 错误策略
`on_error: abort`。捕获属于**原子操作**：写记忆失败就应当整条失败并告知，
不能"文件写了但记忆没写"——那会制造用户以为已记住的假象。
