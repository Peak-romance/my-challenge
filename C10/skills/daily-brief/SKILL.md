# daily-brief · 当日简报

## 这个技能解决什么
每天开工前需要回答三个问题：**今天几号？还有什么没闭环？我关心的东西是什么？**
人工每次都要翻聊天记录、翻便签，属于典型的高频重复任务，因此抽象为技能。

## 契约（机器读 skill.json，人读这里）
| 输入 | 必填 | 默认 | 说明 |
| --- | --- | --- | --- |
| focus | 否 | "" | 本次简报聚焦的主题 |

| 步骤 | 工具 | 作用 |
| --- | --- | --- |
| now | `time.now` | 时间锚点，避免"简报无日期" |
| st | `memory.state` | 读 S 层：未闭环事项、最近任务、turns |
| loops | `format.bullets` | 把 S 层的 list 渲染为勾选框 |
| focus | `memory.search` | 从 K/A 层召回"关注点/偏好/约定" |
| prio | `format.bullets` | 渲染为项目符号 |

## 错误策略
`on_error: continue`。简报是**聚合型**任务，某个信息源缺失（例如 S 层为空）
不应导致整份简报失败——缺失项以占位文案呈现，反而暴露了记忆缺口。
